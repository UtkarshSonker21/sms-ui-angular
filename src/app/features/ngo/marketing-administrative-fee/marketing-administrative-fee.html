How this value is used
When a sponsor (donor) funds a student, Marketing displays the student's total cost as:
Total = University expenses × (1 + fee%)
Only the Kafaat Committee can change this value. Changes apply to new donor-facing cost views only — already-issued donor reports keep the percentage they were generated with.
