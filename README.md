# Scholarship Management System - Angular

## Project

Frontend application for Scholarship Management System.

Technology Stack

- Angular 20
- Angular Material
- Bootstrap 5
- SCSS
- Font Awesome
- TypeScript

---

## Prerequisites

Install the following before running the project.

### Node.js

Version

22.23.1

Verify

```bash
node -v
```

Expected

```
v22.23.1
```

---

### npm

Version

10.9.8

Verify

```bash
npm -v
```

Expected

```
10.9.8
```

---

### Angular CLI

Install

```bash
npm uninstall -g @angular/cli
npm install -g @angular/cli@20.3.31
```

Verify

```bash
ng version
```

Expected

```
Angular CLI: 20.3.31
```

---

## Clone Project

```bash
git clone https://github.com/UtkarshSonker21/sms-ui-angular.git

cd sms-ui
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Project

```bash
ng serve
```

Application

```
http://localhost:4200
```

---

## Build

```bash
ng build
```
